Added more items to the `codemelted.dev` website to fully prep it for usage. Consolidated assets to the website from the `codemelted.com` website. Once that gets defined, will start building out the `codemelted` CLI native command. <mark>THIS IS TRULY ALPHA. NOT PRODUCTION READY YET.</mark> |
