    FEATURES

    The codemelted.js is an ES6 developed module focusing on client-side front end domain use cases. This is accomplished by leveraging the Web APIs available within a Browser / Web Worker runtimes. The Web APIs provide everything a client-side app requires to build Single Page App (SPA), Progressive Web App (PWA), or just general static websites. All of this without the need of a heavy framework.

    Any module API violation will result in a CModuleError thrown with a full stack trace of the violation.

    GETTING STARTED

    Clone / Fork

    When you clone / fork the codemelted.js Project repo, you will need to install tools to properly build the project. The following represents how to set up those tools.

    1. Install PowerShell Core for your given operating system.
    2. Navigate to codemelted.js Project repo location.
    3. Open a terminal and execute ./build.ps1 --setup. Follow the instructions to install all the necessary repo tooling.
    4. Once completed, execute ./build.ps1 --help to gain an understanding of how to build the project in the future.

    Content Delivery Network (CDN)

    The codemelted.js module is hosted on GitHub and delivered via the jsdelivr CDN. The following represents the URLs for accessing the module. These can be utilized with import statements within JavaScript or as part of the <script type="module"></script> tags of a website.

    • Latest Version (Risky):
    https://cdn.jsdelivr.net/gh/codemelteddev/codemelted.js/codemelted.js
    • Version Controlled (Safest):
    https://cdn.jsdelivr.net/gh/codemelteddev/codemelted.js@XX.Y.Z/codemelted.js

    NOTES:

    1. The @XX.Y.Z corresponds to the releases of the codemelted.js Project as identified on GitHub.
    2. XX corresponds to the year of the release. A change in this value resets Y and Z to 0 respectively.
    3. Y corresponds to an API breaking change. A change in this number resets Z.
    4. Z corresponds to a newly delivered feature / bug fix that should not break other API functions.

    USAGE

    ES6 Module Import Example

    // Import whole module statically via URL or local path
    import * as codemelted from "path/to/codemelted.js";

    // Import elements to use statically via URL or local path
    import { exported_element } from "path/to/codemelted.js";

    // Dynamically import all module elements to named variable
    let codemelted = await import("path/to/codemelted.js");

    Via Script Tag in HTML File

    <script type="module">
    // Use the import examples above to utilize the script functions.
    </script>

    And with your imports in place, explore the SDK to utilize the domain use case API of your choice. They will have the details of the API call along with examples.
