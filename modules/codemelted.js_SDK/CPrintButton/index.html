    Class CPrintButton

    <cm-print-button> Subcomponent Documentation

    A specialized instance of <cm-button> that completely locks down the text ("Print") and icon (🖨️) so they cannot be overwritten.

    USAGE

    Content passed between the tags is ignored to preserve structural intent:

    <cm-print-button></cm-print-button>
    <cm-print-button icon-only></cm-print-button>

    THEMING (SAME EXPOSED CSS VARIABLES)

    This component accepts the exact same styling variables as <cm-button>: --padding, --gap, --border-radius, --border, --font-size, --font-weight, --bg-color, --hover-bg-color, --color, --hover-color

    Example:

    cm-print-button {
      --border: none;
    }
    Note

    Even though this extends CButton, you need to manage styles on specific tag name as shown above.

    SELF-MANAGED AVAILABILITY

    Upon entering the DOM, this component automatically determines if print is available. If the internal verification fails, the button quietly applies "display: none" to itself internally logging a warning to the console.
