    Function async_timer

    • async_timer(
          params: {
              interval: number;
              name: string;
              rx_handler: CProtocolEventHandler<CTimerEvent>;
          },
      ): CTimerProtocol

      Create an asynchronous timer set on a specified interval. When the event is fired, the rx_handler will receive the event.

      Parameters

      • params: {
            interval: number;
            name: string;
            rx_handler: CProtocolEventHandler<CTimerEvent>;
        }

        The named parameters

        • interval: number

          The interval the timer protocol will fire a CTimerEvent.

        • name: string

          Identification for the protocol.

        • rx_handler: CProtocolEventHandler<CTimerEvent>

          The receive handler for processing the event.

      Returns CTimerProtocol

      Example

      // Create a timer protocol that fires on a given interval
      let timer = async_timer({
        name: "timer",
        interval: 250, // 250 millisecond interval
        rx_handler: (evt) => {
          // Handle timer firing events.
        }
      });

      // Later when done.
      timer.terminate();
